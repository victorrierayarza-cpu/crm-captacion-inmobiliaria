# CRM Captación Inmobiliaria

Aplicación web (un solo archivo, sin servidor) para **organizar la captación de vendedores y compradores particulares** de inmuebles.

## Qué hace
- Tablero de **leads** (vendedores / compradores) con estados: Nuevo → Contactado → Interesado → Cerrado / Descartado (arrastra las tarjetas).
- Marca si el particular **ya tiene inmobiliaria** para priorizar oportunidades.
- **Plantillas de mensaje** con variables (`{nombre}`, `{zona}`, `{inmueble}`…) para contactar por WhatsApp/email con un clic.
- **Agenda** de próximos seguimientos.
- Botones rápidos de **WhatsApp** y **Llamar**.
- **Copia de seguridad** (exportar/importar JSON) y exportación a **CSV/Excel**.

## Privacidad y datos
- Los datos de los leads se guardan **solo en tu navegador** (`localStorage`). No se suben a ningún servidor ni a este repositorio.
- Haz **exportaciones de copia** con frecuencia desde el botón «Datos».

## Uso responsable (RGPD / LSSI-CE)
Esta herramienta **no rastrea portales ni envía mensajes automáticos**. Sirve para organizar tu prospección; el contacto lo realizas tú y debes recabar el consentimiento de las personas antes de enviarles comunicaciones comerciales.

## Cómo usarla
Abre la URL de GitHub Pages del repositorio, o abre `index.html` en tu navegador.
